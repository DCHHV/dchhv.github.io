## I have learned to solder and want to solder more. What do I do?

### Learn to create your own

The number of SAO circuits around DEFCON is a testament to how anyone with a basic knowledge and some learned skills can create something to solder. Take a simple circuit, ie some LEDs and a power source, add some art work, and you have a kit. It is literally harder to come up with a use, than it is to learn the skills needed to design a circuit, do the layout in software and order a PCB.

Don't agree? Spend sometime in the HHV and you will soon have all the skills needed and know several different software packages where you can get all you need to have parts ordered and PCBs coming.

### But I don't have any ideas on what to make

There are a number of hobbies that provide a rich backdrop of electronic needs.

- HAM Radio and Software Defined Radio (SDR)
- Music (Electronic filters in peddles, synthesizers, circuit bending, etc)
- Appliance repair ( [Repair Cafes](https://www.repaircafe.org/en/) are a thing)
- Drones and RC (boats, planes, cars, etc)
- Physical pentesting
- Home automation
